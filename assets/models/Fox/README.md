# Fox (sample animated model)

Source: [Khronos glTF-Sample-Assets — Fox](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox)
File: `Fox.glb` (binary glTF, ~159 KB), commit `9429648735279342b4c32b8745f7904196607379` of `KhronosGroup/glTF-Sample-Assets`.

Used by ShaderEditor as a small sample asset to exercise Assimp model import,
skeletal animation (`gBones`), and diffuse-texture binding
(`texture_diffuse1`) — see spec
[004-editor-refinements-phoenix-vars-assimp](/C:/CODE/ShaderEditor-AI/specs/004-editor-refinements-phoenix-vars-assimp/spec.md).

Contains three animation clips driving the same skeleton: Survey, Walk, Run.
