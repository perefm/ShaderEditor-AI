# Normal-Tangent Test (bump-mapping sample)

Source: [Khronos glTF-Sample-Assets - NormalTangentTest](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/NormalTangentTest)

File: `NormalTangentTest.glb` (~1.7 MB), downloaded from the Khronos
`glTF-Sample-Assets` repository at commit
`855bad5e79527b68e753b594a728b8054af30969`.

This model contains embedded normal-map textures and is intended to verify
normal-map tangent handling. It is static rather than skeletal, so use
`bump_mapping.glsl` to inspect its normal maps. The new
`bone_animation_bump_mapping.glsl` shader also supports the same material and
normal-map layout for animated models such as Fox.
