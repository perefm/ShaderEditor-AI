# Cesium Man (sample animated PBR model)

Source: [Khronos glTF-Sample-Assets — Cesium Man](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CesiumMan)
File: `CesiumMan.glb` (binary glTF, ~438 KB), commit `9429648735279342b4c32b8745f7904196607379` of `KhronosGroup/glTF-Sample-Assets`.

Used by ShaderEditor as a small sample asset to exercise Assimp model import
of a `pbrMetallicRoughness` glTF material combined with skeletal animation
(`gBones`) — see spec
[004-editor-refinements-phoenix-vars-assimp](/C:/CODE/ShaderEditor-AI/specs/004-editor-refinements-phoenix-vars-assimp/spec.md),
in particular the bundled `assets/shaders/pbr_animation.glsl` example shader.

Animated and skinned character with the Cesium logo, one walking animation
clip.
